# 로또·연금복권 프로

동행복권 **로또 6/45**와 **연금복권720+**의 당첨 통계를 분석하고, 번호를 생성·저장·관리하는 무료 웹앱입니다.

**▶ 앱 바로가기:** https://twbeatles.github.io/lotto-pension-pro-webapp/

> 모든 번호 추천은 과거 통계 기반 참고용입니다. 당첨을 보장하지 않습니다.

---

## 주요 기능

| 탭 | 기능 요약 |
|---|---|
| **번호 생성** | 꼭 넣을 번호·뺄 번호 등 조건을 정해 로또 6/45 번호 조합 생성, 즐겨찾기·구매 번호 저장 |
| **당첨 통계** | 역대 당첨 번호 출현 빈도·분포 분석 |
| **번호 추천** | 지난 당첨 기록(자주 나온 번호, 최근 흐름, 쉬는 기간 등)을 바탕으로 5조합 추천 |
| **연금복권** | 연금복권720+ 통계·추천·저장·당첨 확인·CSV 내보내기 |
| **시뮬레이션** | 고른 방식으로 과거에 샀다면 얼마나 맞았을지 확인 |
| **당첨 확인** | 저장한 번호·로또 용지 QR을 당첨 번호와 비교 (1~5등 당첨 시 축하 효과) |
| **데이터 관리** | 구매 번호·즐겨찾기·생성 기록·회차 묶음 관리, 백업 파일 저장/불러오기 |

## 사용 방법

### 번호 생성 (로또 6/45)

1. **번호 생성** 탭을 엽니다.
2. 필요하면 조건을 정합니다. (모두 선택 사항)
   - **꼭 넣을 번호**: 반드시 포함할 번호 (최대 5개)
   - **뺄 번호**: 포함하지 않을 번호
   - **연속 번호 줄이기**: 11, 12, 13처럼 이어진 번호가 많이 나오지 않게 합니다.
   - **추천 방식·세부 조건**: 번호 고르는 방식, 홀수 개수, 합계 범위 등을 직접 정합니다.
3. `번호 생성하기`를 누릅니다.
4. 마음에 드는 조합은 ⭐ **즐겨찾기** 또는 🎟️ **구매 번호**로 저장합니다. 구매 번호는 추첨이 끝나면 자동으로 결과가 표시됩니다.

### 번호 추천 (로또 6/45)

1. **번호 추천** 탭을 엽니다.
2. 원하는 **추천 방식**을 고릅니다. 아래 「추천 방식 한눈에 보기」에서 설명을 보고 눌러서 고를 수도 있습니다.
3. **분석 강도**를 고릅니다. 처음이라면 `기본`을 권장합니다.
4. `추천 시작`을 눌러 결과를 받습니다.
5. 「왜 이 번호인가요?」에서 추천 근거를 보고, 마음에 드는 번호를 **구매 번호로 저장**합니다.

> **번호 생성**, **번호 추천**, **연금복권** 결과 화면에 표시되는 **재현 코드**를 복사해, 각 탭의 `같은 번호 다시 만들기 코드`(또는 연금복권 `시드`) 입력란에 넣으면 같은 결과를 다시 만들 수 있습니다.

### 연금복권720+ 추천

1. **연금복권** 탭을 엽니다.
2. 전략을 선택합니다.
   - 혼합 균형, 자리별 강세, 끝자리 집중, 쉬고 있는 조 우선, 오래 안 나온 숫자, 보너스 흐름, 완전 무작위 등
3. 원하는 필터를 설정합니다. (조 선택, 자리 고정/제외, 숫자 합계, 홀수 비율 등)
4. `추천 시작`을 눌러 번호를 생성합니다.
5. 결과 상단 **재현 코드**로 같은 추천을 다시 실행할 수 있습니다.
6. 번호를 개별 저장하거나, 같은 6자리로 여러 조를 **확장 저장**할 수 있습니다.

### 당첨 확인

- **로또 6/45**: **당첨 확인** 탭에서 저장된 번호를 최신 회차 당첨 번호와 자동 비교합니다. 판매점 용지의 동행복권 공식 QR(`m.dhlottery.co.kr`, `dhlottery.co.kr/qr.do`)을 스캔하면 회차와 게임 번호가 채워집니다. 자동·수동·반자동 구분(`m`/`q`/`n`/`s`)이 있는 용지도 인식합니다.
- **연금복권720+**: **연금복권** 탭 저장 목록에서 대상 회차 우선 확인 또는 최신 회차 참고 비교를 합니다.

### 회차 묶음 (여러 회차 번호 미리 만들기)

몇 주 동안 살 번호를 한 번에 만들어 두고 싶을 때 **회차 묶음**을 활용합니다.

- 로또 6/45(번호 생성 탭)와 연금복권720+(연금복권 탭) 모두 지원합니다.
- 시작 회차, 기간, 회차마다 살 게임 수를 정하면 회차별 구매 번호가 한 번에 저장되고, 추첨 결과도 회차별로 확인할 수 있습니다.

### 데이터 백업 및 복원

저장한 번호·회차 묶음·설정을 파일로 백업할 수 있습니다.

**백업하기**
1. **데이터 관리** 탭 > `백업 파일 저장`
2. JSON 백업 파일이 다운로드됩니다.

**복원하기**
1. **데이터 관리** 탭 > `백업 파일 불러오기`
2. 저장해둔 백업 JSON 파일을 선택합니다.
3. 덮어쓰기 전에 자동으로 안전 백업이 먼저 생성됩니다.

> 백업 파일은 최대 32 MB까지 가져올 수 있습니다.

## 앱 설치 (PWA)

스마트폰이나 PC 브라우저에서 홈 화면에 설치해 네이티브 앱처럼 사용할 수 있습니다.

- **Android / Chrome**: 주소창 오른쪽 `설치` 아이콘 탭
- **iOS / Safari**: 하단 공유 버튼 → `홈 화면에 추가`
- **PC / Chrome · Edge**: 주소창 오른쪽 설치 아이콘 클릭

설치된 앱은 오프라인 상태에서도 저장된 데이터와 기본 기능을 사용할 수 있습니다.

## 자주 묻는 질문

**Q. 번호 추천이 당첨을 보장하나요?**
아닙니다. 모든 추천은 과거 통계 기반 참고용이며, 로또 추첨은 완전한 무작위입니다.

**Q. 저장한 데이터가 사라졌어요.**
앱 데이터는 브라우저 로컬 저장소에 보관됩니다. 브라우저의 쿠키·사이트 데이터를 전체 초기화하면 함께 삭제됩니다. **데이터 관리 > 백업 파일 저장**으로 정기 백업을 권장합니다.

**Q. 여러 기기에서 같은 데이터를 쓰고 싶어요.**
기기 간 자동 동기화는 지원하지 않습니다. **백업 파일 저장**으로 파일을 만든 뒤, 다른 기기에서 **백업 파일 불러오기**로 복원하세요.

**Q. 오프라인에서도 사용할 수 있나요?**
PWA로 설치하면 오프라인 상태에서도 저장된 데이터와 기본 기능을 사용할 수 있습니다.

## 고급: 데이터 연결 주소

최신 로또·연금복권720+ 당첨 데이터를 브라우저에서 갱신하려면 Cloudflare Worker 프록시를 직접 배포하고
**설정 > 당첨 번호 업데이트 > 고급 · 연결 상태 자세히 > 데이터 연결 주소**에 입력하는 것을 권장합니다.

고급 연결 주소를 비워 두면 앱은 **기본 자동 동기화**를 시도합니다. 브라우저는 동행복권 공식 API를
단순 GET CORS로 직접 호출하고, 실패 시 `corsproxy.io`·`CodeTabs` 같은 **공개 CORS 중계**를 경유할 수 있습니다.
`corsproxy.io`는 현재 API 키가 없으면 HTTP 401을 반환하므로 기본 경로가 아닙니다.
가용성·속도·개인정보 측면에서 자체 Worker 배포가 더 안정적입니다.

로또 `/proxy/latest` 주소를 설정하면 연금복권은 같은 Worker의 `/proxy/pension720/list`로 자동 연동됩니다.
주소창 `?proxyUrl=` 파라미터는 **확인 대화상자에서 동의한 뒤에만** 적용됩니다. 확인 UI를 쓸 수 없으면
해당 주소는 무시하고 저장된 설정·기본 자동 동기화를 사용합니다.

번호 추천·생성의 **분석 강도**는 데스크톱에서는 `기본`을 권장하고, 모바일·터치 환경에서는 더 가벼운
`빠름`으로 시작할 수 있습니다(직접 변경 가능).

→ 프록시 배포 방법: [proxy/README.md](proxy/README.md)
